# Cinnamon

Cinnamon은 개인용/내부용 Slack-first AI agent bot입니다.

Slack에서 GitHub PR 알림을 받고, PR 요약과 리뷰를 요청하고, 개발 작업이나 장애 대응을 자연어로 맡기는 흐름을 만들고 있습니다. 위험하거나 상태를 바꾸는 작업은 Slack에서 사용자가 명시적으로 `yes` 승인한 뒤에만 실행합니다.
